# 物理シミュレーション集

公開中の物理シミュレーションの一覧（URLとQRコード）です。

- 公開ページ: https://rmurayama1998-cell.github.io/physics-simulations/
- この一覧ページのQRコード: `qr.png` / `qr.svg`
- 印刷用: `物理シミュレーション集.pdf`

一覧を変えるときは `make_page.py` の `SECTIONS` を書きかえて `python make_page.py` を実行します（`template.html` から `index.html` と `qr.png` を作ります）。
